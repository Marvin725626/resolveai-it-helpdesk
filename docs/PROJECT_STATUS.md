# ResolveAI 功能与验证状态

本次验收日期：2026-10-16。目标为可运行、可演示、核心流程完整且验证可重复的开发 MVP。

| 范围 | 实现与实测 |
| --- | --- |
| 身份与工作区 | 继承 JWT 身份，Helpdesk API 按租户 / 用户 / 支持角色约束；隔离回归覆盖跨租户与同事权限 |
| 团队成员邀请 | 所有者 / 管理员创建和撤销 48 小时邀请；新成员可选择员工 REQUESTER 或支持专员 SUPPORT_AGENT，令牌摘要存储、单次消费与租户隔离 |
| 员工自助门户 | 独立员工角色、个人请求统计、服务大厅、结构化申请、本人跟进与通知；员工后台接口由服务端限制 |
| 服务目录管理 | 管理员创建、发布与归档，表单预览、版本冲突检查、历史修订与不可变申请快照 |
| LangGraph 诊断 | 分类、混合检索、证据门控、最多两次检索、只读工具、引用回答、转人工 |
| 知识维护 | UTF-8 文本导入、编辑重建索引、版本快照、停用启用、恢复为新版本、导出与检索测试 |
| 工单协作 | 实际接手人、管理员交接 / 释放、脱敏原因、防重复、状态机、完整历史分页、更新冲突检查 |
| 解决与验收 | 结构化公开解决记录、分轮保留、本人确认关闭及可选满意度，独立于AI诊断反馈 |
| 经验入库 | 解决记录整理知识草稿、作者修改、管理员审核 / 驳回、发布后更新版本与检索 |
| 公开协作与附件 | 本人跟进、公开回复与内部备注分开、截图 / 日志按工单权限私有访问、个人通知 |
| 主动报障 | 用户直接提交问题，独立记录实际报障人及来源，接入现有处理、附件和解决评分闭环，45项回归、真实PG并发与浏览器验收通过 |
| 日常分诊 | 未完成工单优先级调整、原创建时限重算、原因与前后目标时间记录、个人保存筛选视图 |
| 团队运营 | 当前积压与接手人工作量、独立窗口的解决轮次及满意度、明确口径与JSON导出 |
| 队列与历史 | 数据库分页及筛选、个人报障关键词/状态/来源查找、支持队列来源分流、跨页摘要导出上限、按需读取完整证据 |
| 运行恢复 | 断线 / 刷新后读取原结果，三分钟以上旧运行标记中断后重试 |
| 观察与维护 | 实际运行指标、用户反馈、数据库及配置检查、SQLite 数据库与私有附件离线 bundle、独立 Docker/PostgreSQL 演练入口 |
| 质量检查 | 基础后端回归与各模块隔离业务检查、恢复 bundle 定向测试、16 个隔离离线场景、CSV 检查、类型 / 生产构建、格式及依赖审计、真实浏览器操作 |
| 展示资料 | 当前 README、流程图、API 和运维说明、实机截图与真实版本记录 |

1005 条工单等大样本只存在于测试数据库，用于验证查询边界，不代表真实客户规模。离线报告的通过率仅针对 16 个固定样本。

SQLite bundle 的隔离恢复演练已通过定向测试，验证临时恢复副本可登录并读取合成工单、通知、个人视图和附件；这不是现有实例覆盖恢复。PostgreSQL / Docker 三容器部署、真实向量检索、迁移、业务闭环、两类并发检查、重建后卷持久化与 dump/restore 合成演练已在本地通过，见[验证记录](VALIDATION.md)；尚未形成生产环境证据。真实 LLM 调用与企业工具接入尚未验证。邀请依赖管理员手动分享链接，不投递或验证邮箱。图恢复为最终结果读取和旧记录处理，没有节点级持久 checkpointer。应用级事件记录可由数据库管理员改动，不是不可篡改合规审计。共享部署仍需运行监控和真实环境验收。
