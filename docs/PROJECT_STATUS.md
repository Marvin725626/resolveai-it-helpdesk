# ResolveAI 功能与验证状态

本次验收日期：2026-10-13。目标为可运行、可演示、核心流程完整且验证可重复的开发 MVP。

| 范围 | 实现与实测 |
| --- | --- |
| 身份与工作区 | 继承 JWT 身份，Helpdesk API 按租户 / 用户 / 支持角色约束；隔离回归覆盖跨租户与同事权限 |
| LangGraph 诊断 | 分类、混合检索、证据门控、最多两次检索、只读工具、引用回答、转人工 |
| 知识维护 | UTF-8 文本导入、编辑重建索引、版本快照、停用启用、恢复为新版本、导出与检索测试 |
| 工单协作 | 实际接手人、管理员交接 / 释放、脱敏原因、防重复、状态机、完整历史分页、更新冲突检查 |
| 队列与历史 | 数据库分页及筛选、跨页摘要导出上限、按需读取完整证据 |
| 运行恢复 | 断线 / 刷新后读取原结果，三分钟以上旧运行标记中断后重试 |
| 观察与维护 | 实际运行指标、用户反馈、数据库及配置检查、私有 SQLite 在线备份 |
| 质量检查 | 39 项后端回归、16 个隔离离线场景、CSV 检查、类型 / 生产构建、格式及依赖审计、真实浏览器操作 |
| 展示资料 | 当前 README、流程图、API 和运维说明、实机截图与真实版本记录 |

1005 条工单等大样本只存在于测试数据库，用于验证查询边界，不代表真实客户规模。离线报告的通过率仅针对 16 个固定样本。

真实 LLM 调用、PostgreSQL / Docker 集成与企业工具接入尚未验证。图恢复为最终结果读取和旧记录处理，没有节点级持久 checkpointer。应用级事件记录可由数据库管理员改动，不是不可篡改合规审计。共享部署还需要数据库迁移、运行监控和真实环境验收。

上游原始审计 / 招聘评估文档仅作为来源资料保留，其评分和生产结论不构成本项目验证证据。当前证据见 [VALIDATION.md](VALIDATION.md)、[evaluation.offline.json](evaluation.offline.json) 和 GitHub Actions。
