# 三分钟演示与复现

先按 README 安装并启动，在 http://127.0.0.1:5174 使用预填本地演示账号登录。

## 演示步骤

1. **有依据的回答（30 秒）**：在智能诊断输入“如何安装公司批准的办公软件？”，展示 APP-001 引用与节点轨迹。说明当前使用离线规则和 SOP 摘录。
2. **工具到工单（45 秒）**：输入“VPN 连不上，提示认证超时，怎么排查？”，查看 VPN-001、模拟服务降级与自动人工工单；打开工单上下文，再接手处理、标记解决。
3. **筛选与导出（30 秒）**：工单队列搜索 VPN，选择状态和优先级，导出当前结果。取消过滤后可看到完整的最近 100 张列表。
4. **运营观测（45 秒）**：打开运营看板，切换 7 / 30 天，展示每日量、分类、转人工率与 P95，展开每日数据表，下载指标 JSON。说明当前账号 / 工作区范围以及离线耗时限制。
5. **代码与验证（30 秒）**：打开 GitHub 的架构图、关键代码与 Actions，说明隔离测试覆盖证据缺失、重复请求、工作区隔离和统计口径。

## 自动浏览器演示

该脚本需要 Playwright 和 Chromium，不作为项目运行的必需依赖。启动服务后，在项目目录执行：

```powershell
cd frontend
npm install --no-save --package-lock=false playwright
npx playwright install chromium
cd ..
node scripts/smoke-browser.cjs
```

它通过界面登录、运行两个真实诊断、验证看板与下载、组合筛选、空结果和 390px 布局，并更新 `docs/resolveai-*.png`。它会在本地演示数据库新增诊断与工单。请仅在开发环境运行。

可设置 `RESOLVEAI_URL`、`RESOLVEAI_EMAIL`、`RESOLVEAI_PASSWORD` 指向开发服务。自定义浏览器路径用 `CHROMIUM_PATH`，已有 Playwright 模块用 `PLAYWRIGHT_MODULE`。密码和令牌不写入脚本输出或仓库。

## 统计定义

- 日期：香港时间的日历日，包含今天；API `days` 允许 1–90，UI 预设 7 / 30 / 90。
- 请求量：窗口内当前账号所有运行记录；完成数：`status=completed`。
- 转人工率：完成诊断中 `escalate=true` 的比例。
- 证据通过率：完成诊断中 `supported=true` 的比例；只是规则门控结果，不是正确率。
- 平均与 P95：只使用非负数值耗时的完成记录，P95 为排序后的第 `ceil(0.95*N)` 个值。
- 工单分布：当前工作区全部时间的状态计数。
- CSV：当前加载列表中筛选出的最多 100 张工单，所有单元格带引号，危险公式前缀添加单引号。

真实模型、企业工具接入、PostgreSQL 与 Docker 需要另行配置和验证；截图中的服务状态是模拟数据。
